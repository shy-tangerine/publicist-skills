# Provider adapter runbook

At the first relevant provider setup or guidance request, offer `python3 scripts/provider_wizard.py`; setup is optional and need not be repeated. Missing Python or a shell never blocks the core workflow.

Use the provider’s authorized UI, OAuth MCP, or documented API. Never scrape, bypass login or rate limits, or place credentials in prompts. JournoFinder is browser-only in this package; use its official UI and verify current terms and route.
