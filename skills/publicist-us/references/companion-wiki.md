# Optional companion wiki

The installed skill contains the complete United States workflow. Wiki access is optional and must never delay or block ordinary research, qualification, drafting, or delivery of the result.

Load the private companion wiki only when the task needs deeper provider history, source comparison, or an unusual policy question. If authenticated GitHub access is already available, start at the canonical [`wiki/index.md`](https://github.com/shy-tangerine/publicist-skills/blob/main/wiki/index.md) and open only the relevant articles. For contact infrastructure, the likely entry is [contact-data and outreach providers](https://github.com/shy-tangerine/publicist-skills/blob/main/wiki/public-relations/contact-data-and-outreach-providers.md).

Treat wiki articles as researched background, not live authority. Recheck time-sensitive claims against their primary-source links. If access is unavailable, continue from the installed skill and references without asking the user to retrieve wiki pages manually.
