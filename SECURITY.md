# Security policy

> **Private preview.** Access to `shy-tangerine/publicist-skills` requires authorization. Submit security reports through that repository's private vulnerability reporting form.

Report vulnerabilities privately at https://github.com/shy-tangerine/publicist-skills/security/advisories/new.

## Supported versions

Security fixes apply to the latest release and the default branch.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for vulnerabilities, prompt-injection paths, approval bypasses, unsafe data handling, or credential exposure. Do not open a public issue containing sensitive details.

Include the affected file or workflow, impact, reproduction steps using fictional data, and a suggested mitigation when available. Never submit real journalist contact data, client records, tokens, private correspondence, or provider exports.

Provider-policy corrections that contain no sensitive information may use a normal issue.
